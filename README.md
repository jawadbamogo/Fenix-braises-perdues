FENIX - ARÈNE DES BRAISES
=========================

GAMEPLAY
- Grande arène complètement fermée
- Déplacement : WASD ou flèches.
- 3 vies représentées par des cœurs.
- Les ennemis se déplacent vers Fenix.
- Si un ennemi touche Fenix : perte d'un cœur + retour au point de départ.
- Les pointes font la même chose.
- À 0 cœur : la partie entière recommence avec 3 cœurs.
- Touche R : recommencer immédiatement.
